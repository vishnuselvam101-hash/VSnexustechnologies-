# A/B bench: build/v12 6bf7749 vs build/v13-final (f561449 / a798d89) — SIMULATED — SUPERSEDED by ../ab-final2

**Record of the pre-fix engine.** The scheduler measured here could skip a distinct strand that shared a payload
window with a verified one (fixed in f7586b9, CHANGELOG 13.0.0 "Fixed"); the report quotes `../ab-final2`, the same
run on the final engine. Nothing below was altered.

Same harness and method as the V12 benches (`bench.py run`: BASE_TREE = pristine build/v12 checkout 6bf7749, inputs
generated by the V12 tree, both trees decode the same files, paired per seed with the configuration order reversed on
odd seeds, one discarded warm-up per configuration per scenario, n = 5 seeds, 3 for 16 MiB; process-tree RSS sampled
every 0.5 s). Ratio = v12 seconds / v13 seconds (> 1 means V13 faster); 95 % CI = percentile bootstrap of the median
ratio, which at n = 5 is the min–max range. Files: `e2e.jsonl` (126 rows), `warmup.jsonl` (26 rows), `e2e-summary.json`,
`summary.txt`, `vs-aa.txt` (each scenario against the A/A noise band of `../baseline-aa`, from `compare_aa.py`),
`run.log`, `operator-notes.txt`. Every input is produced by the VNX-DNA channel simulator; no DNA was synthesised,
stored or sequenced. One host (4C/8T Xeon Gold 6240, Python 3.12.3); the numbers are this host's.

The tree measured: f561449 for the nine scenarios run on 2026-10-17 (indel-w1/w2/w4/w8, indel-rc-w4, indel-dropout-w4,
clean-w4, substitution-w4, indel-64k-w1) and a798d89 for the four run on 2026-10-18 after the first session stopped
(indel-16m-w4, encode-1m-w1, encode-4m-w1, encode-4m-w4). The two commits between (8c7ea15, a798d89) change docs,
scripts, evidence files, one test's timing race and the volume's key handling — nothing on the encode or decode path.
`stale_libraries: ["engine"]` on the v13 rows is an mtime artefact: the crate's only source change after the library
was built is five appended `#[cfg(test)]` test modules (see `operator-notes.txt`).

trees and equal to the input archive, 0 false successes. The engine rung `stream` was taken on every V13 decode (no

process with a thread pool; V12's grows with the worker processes. Scaling versus 1 worker: v12 1.79 / 2.56 / 2.59 at
