# A/B bench: build/v12 6bf7749 vs build/v13-final f7586b9 (the final engine) — SIMULATED

The run the V13 benchmark report quotes. Same harness, method and files as `../ab-final` (`bench.py run`, BASE_TREE =
pristine build/v12 checkout 6bf7749, inputs generated by the V12 tree, paired per seed with alternating order, one
discarded warm-up per configuration per scenario, n = 5 seeds, 3 for 16 MiB; process-tree RSS sampled every 0.5 s;
ratio = v12 seconds / v13 seconds, CI = percentile bootstrap of the median ratio = min–max at n = 5). All 13
scenarios in one run on 2026-10-18 (`operator-notes.txt`), 126 rows, every kernel and the engine native and current
(`stale_libraries` empty on every row). Every input is produced by the VNX-DNA channel simulator; no DNA was
synthesised, stored or sequenced; one host (4C/8T Xeon Gold 6240).
