# VNX-DNA-1 format
A dataset directory contains deterministic `manifest.json` and ASCII `strands.fasta`. The manifest is canonical JSON and records format/version, UUID, original SHA-256 and sizes, transformation configuration, and strand count. Each FASTA record uses `>VNX1|dataset_uuid|index|total|payload_bytes|payload_sha256`, followed by a four-base-per-byte two-bit A/C/G/T sequence. The decoder rejects mismatched format, metadata, length, checksum, dataset identifier, and missing indexes. The baseline is a computational representation, not a claim of synthesis suitability.
