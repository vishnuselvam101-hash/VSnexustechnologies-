# V12 end-to-end benchmark report: V11 (v11.0.0) vs V12 (build/v12)

SIMULATED: every input is produced by the VNX-DNA channel simulator; no DNA was synthesised, stored or sequenced.
One host, one channel family; the numbers are this host's, not a product claim. Committed runs:
`experiments/v12/bench/baseline-aa` (A/A noise floor), `ab-pass2` (00bd160), `ab-pass1` (ad9bff6),
`ab-orient` (812ed7d, the release code). Each directory holds `e2e.jsonl`, `e2e-summary.json`, `summary.txt`,
`vs-aa.txt`, `run.log`, `operator-notes.txt` and a README.

## 1. Method

`experiments/v12/bench/bench.py run` (same method as the V11 report): inputs are generated by the v11.0.0 tree
(`datagen` random bytes → archive → strands → simulated reads), both trees decode the same files, paired per seed with
the configuration order reversed on odd seeds, one discarded warm-up per configuration per scenario, n = 5 seeds (3 for
16 MiB). Ratio = v11 seconds / v12 seconds (> 1 means V12 faster), bootstrap CI of the median ratio (10 000 resamples).
Peak process-tree RSS is sampled by the harness. `compare_aa.py` calls a scenario "beyond noise" only when its CI does
not overlap the A/A CI (the same tree measured against itself, `baseline-aa`). Outputs are compared by SHA-256 against
the input archive; a false success is a SUCCESS with a different output (0 occurred).

Scenarios: 4 MiB indel decode (substitution 1 %, insertion 0.2 %, deletion 0.2 %, coverage 5) at 1/2/4/8 workers;
the same with 50 % reverse-complemented reads and with 5 % strand dropout (4 workers); clean coverage 3; substitution
2 % coverage 5; 64 KiB indel (1 worker); 16 MiB indel (4 workers); encode 1 MiB and 4 MiB at 1 and 4 workers.

## 2. Environment

4C/8T Linux host (`e2e-summary.json` `host`), Python 3.12, all native kernels built (`python -m vnxdna.native`
reports every kernel native in both trees; V12 adds `orient`). No other load during the runs (`operator-notes.txt`).

## 4. Progression within V12 (same harness, same v11.0.0 base)

| scenario | ab-pass2 (00bd160: parallel pass 2 + shifted scan) | ab-pass1 (ad9bff6: + gathers, early exit, array returns) | ab-orient (812ed7d: + native kernel) |
|---|---|---|---|
| indel-w1 | 0.858 | 0.986 | 1.114 |
| indel-w2 | 0.873 | 1.029 | 1.148 |
| indel-w4 | 0.942 | 1.125 | 1.228 |
| indel-w8 | 0.990 | 1.236 | 1.344 |
| indel-rc-w4 | 0.961 | 1.044 | 1.244 |
| indel-dropout-w4 | 0.990 | 1.182 | 1.269 |
| clean-w4 | 0.664 | 1.131 | 1.042 |
| substitution-w4 | 0.760 | 1.134 | 1.171 |
| indel-64k-w1 | 0.894 | 0.994 | 1.035 |
| indel-16m-w4 | 0.985 | 1.192 | 1.319 |

The first cut (00bd160) was a net slowdown: the five-shift NumPy orientation scan cost more worker CPU than the retry
work it saved, and pass 2 returned one object per symbol through pickle. The gathers and the early exit recovered it;
the native kernel removed the scan from the profile (1.37 s → 0.27 s on 655 755 reads).

## 5. Targets (docs/V12_PLAN.md §4) — disclosed honestly

T1 (w4 ≥ 1.25): **not met**, 1.228 (CI lower bound 1.205 > 1.0). T2 (w1 ≥ 1.15): **not met**, 1.114.

T4 (identical output, 0 false successes): met. T5 (RSS ≤ 1.10 on every decode scenario): **not met** (1.19–1.23 on

## 6. Reproduction

```bash
# pristine v11.0.0 checkout at /root/vnx-dna-lab/v12-base (or any path), native kernels built in both trees
BASE_TREE=/path/to/v11.0.0 VNX_BENCH_OUT=experiments/v12/bench/<dir>/e2e.jsonl PYTHONPATH=src \
  python experiments/v12/bench/bench.py run
VNX_BENCH_OUT=experiments/v12/bench/<dir>/e2e.jsonl PYTHONPATH=src python experiments/v12/bench/bench.py summary
PYTHONPATH=src python experiments/v12/bench/compare_aa.py experiments/v12/bench/<dir>/e2e-summary.json
```
